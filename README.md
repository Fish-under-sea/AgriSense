# 🌱 AgriSense - AI智能大棚农产品监测系统

## 📋 产品概念单页

### 产品名称
**AgriSense** | 代号：Project SmartFarm+

### 一句话Slogan
**"让每一株作物都在AI的注视下科学生长"**

### 用户痛点
- **经验依赖过重**：传统种植靠老农经验，新人难以复制高产技术
- **环境感知滞后**：发现问题时（病害/缺水）已造成实际损失
- **决策凭感觉**：浇水、施肥时机随意，缺乏数据支撑
- **产量质量波动**：无法持续稳定产出高品质农产品

### 解决方案
**一个搭载树莓派的AI农业监测系统，通过多维度数据采集与AI分析，实现科学种植决策：**

| 功能 | 描述 | 技术实现 |
|------|------|----------|
| 📷 **叶片健康监测** | 识别叶片病害、虫害、营养缺乏症状 | OpenCV + 植物病害CNN模型 |
| 💧 **土壤湿度管控** | 实时监测土壤湿度，智能控制灌溉 | 土壤湿度传感器 + 继电器控制水泵 |
| 🌿 **植株生长分析** | 测量株高、冠幅、生长速率 | 双目摄像头 + 视觉测距算法 |
| ☀️ **光合作用评估** | 估算光合作用/呼吸作用强度 | 光照传感器 + CO₂传感器 + 温度传感器 |
| 🤖 **AI种植建议** | 根据综合数据给出农事操作建议 | 本地轻量LLM + 农技知识库 |
| 📊 **生长日报** | 每日生成作物健康报告+预警 | 数据统计 + AI生成分析文案 |

## 🚀 技术栈详情

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 主控 | 树莓派4B（4GB） | 需要运行视觉模型，性能要求较高 |
| 摄像头 | Pi Camera V2 + NoIR（红外） | 红外版可做多光谱分析 |
| 土壤传感器 | Capacitive土壤湿度传感器 | 比电阻式更耐用，不易腐蚀 |
| 环境传感器 | BME680（温湿度、气压、VOC） + SCD30（CO₂） | 一体式传感器节省空间 |
| 视觉模型 | TensorFlow Lite + MobileNetV2 | 轻量化，适合树莓派 |
| 数据存储 | SQLite + CSV | 轻量级，便于导出分析 |
| 控制执行 | 继电器模块 + 电磁阀/水泵/补光灯 | 5V继电器可直接由GPIO控制 |
| 前端可视化 | Flask + ECharts | 提供Web界面，手机可访问 |
| 决策模型 | 规则引擎 + TinyLLaMA | 规则保底，LLM提供自然语言建议 |

## 🔬 详细技术方案

### 1. 叶片健康状况监测
- **采集**：每天定时拍摄叶片RGB图像+红外图像
- **分析**：
  - 病害识别（白粉病、霜霉病、叶斑病等）
  - 虫害识别（蚜虫、红蜘蛛等）
  - 营养缺乏诊断（缺氮黄叶、缺钾焦边等）
- **模型**：基于PlantVillage数据集的迁移学习模型

### 2. 土壤湿度管控
- **采集**：3个点位土壤湿度，每10分钟采样一次
- **控制逻辑**：
  - 低于阈值下限 → 开启滴灌
  - 高于阈值上限 → 停止灌溉
  - 阈值根据作物种类+生长阶段动态调整

### 3. 植株生长状态
- **采集**：顶部垂直向下拍摄+侧面水平拍摄
- **测量指标**：
  - 株高（通过已知参照物换算）
  - 冠幅投影面积
  - 叶片计数
  - 果实数量/大小估算
- **算法**：YOLOv8-nano轻量版检测+分割

### 4. 光合/呼吸作用强度
- **估算模型**：
  - 光合有效辐射(PAR) ≈ 光照强度 × 0.45
  - 光合速率 ≈ f(PAR, CO₂浓度, 温度, 叶面积)
  - 呼吸速率 ≈ f(温度, 生物量)
  - 净光合 = 光合 - 呼吸
- **应用**：判断是否需要补光/通风/降温

### 5. AI种植建议生成
- **输入**：所有传感器数据+视觉分析结果+历史数据
- **输出示例**：
  - "未来3天持续阴雨，建议今天补光2小时"
  - "叶片出现早期白粉病症状，建议增加通风并使用生物制剂"
  - "土壤湿度下降过快，检查滴灌管道是否堵塞"
